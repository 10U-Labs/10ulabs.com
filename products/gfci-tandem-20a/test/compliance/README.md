# Compliance Test Documentation

This directory contains test procedures and results for UL 489 and UL 943 compliance testing.

## Standards

- **UL 489**: Molded-Case Circuit Breakers, Molded-Case Switches and Circuit-Breaker Enclosures
- **UL 943**: Ground-Fault Circuit-Interrupters

## Test Categories

### UL 489 Tests
- [ ] Overload trip calibration
- [ ] Instantaneous trip calibration
- [ ] Dielectric withstand (1500V)
- [ ] Interrupting capacity (10 kAIC)
- [ ] Endurance (6000 cycles)
- [ ] Temperature rise

### UL 943 Tests
- [ ] Trip threshold (4-6mA at 60Hz)
- [ ] Trip time vs. fault current curve
- [ ] Grounded neutral test
- [ ] Reset reliability
- [ ] Rain/humidity exposure
- [ ] Corrosion resistance
